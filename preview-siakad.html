SIAKAD

Academic Information System — scheduling, attendance, grades, student promotion, Excel import, role-based access for schools.

Laravel 12 Tailwind CSS Laravel Breeze Maatwebsite Excel MySQL Vite

Overview

SIAKAD (Sistem Informasi Akademik) is a web-based Academic Information System that digitalizes school administration. It covers student and teacher data management, class scheduling, attendance tracking, grade processing, and report access through role-based accounts (Admin, Teacher, Student, Homeroom Teacher).

The system handles the full academic lifecycle: master data management with Excel import for bulk student/teacher onboarding, teaching schedules accessible by role, daily attendance input and monitoring, grade entry with automated report card (rapor) generation, and student promotion workflows for class advancement.

Built with Laravel 12 and Tailwind CSS using Breeze for authentication, optimized for school administrators and teachers who need a reliable, straightforward system.

Features & Technology

Key Features

  • Role-based authentication — Admin, Teacher, Student, Homeroom Teacher (Laravel Breeze)
  • Master data management — Student and teacher records with CRUD
  • Schedule management — Teaching schedules and student class schedules
  • Attendance tracking — Daily input and monitoring with summaries
  • Grade processing — Entry, calculation, and student report (rapor) viewing
  • Student promotion — Class advancement workflow at year-end
  • Excel import — Bulk import for student and teacher data (Maatwebsite Excel)
  • Profile management — Personal profile and password management per role

Technology Stack

  • Framework: Laravel 12 (PHP 8.2)
  • Frontend: Blade + Tailwind CSS, Vite asset bundling
  • Authentication: Laravel Breeze
  • Database: MySQL with Eloquent ORM
  • Import/Export: Maatwebsite Excel for bulk data
  • Build: Vite for frontend assets
