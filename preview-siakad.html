🎓 Project Overview

SIAKAD (Sistem Informasi Akademik) is a web-based Academic Information System that digitalizes school administration, including student and teacher data management, class scheduling, attendance tracking, grade processing, and report access through role-based accounts.

🛠️ Key Features

  • Role-based authentication (Admin, Teacher, Student, Homeroom Teacher)
  • Student and teacher master data management
  • Teaching schedule and student class schedule access
  • Attendance input and monitoring
  • Grade entry and student report (rapor) viewing
  • Student promotion (class advancement) workflow
  • Excel import for student and teacher data
  • Personal profile and password management

💻 Technology

  • PHP 8.2
  • Laravel 12
  • Blade Template Engine
  • Tailwind CSS
  • Vite
  • MySQL Database
  • Laravel Breeze (Authentication)
  • Maatwebsite Excel (Data Import)
