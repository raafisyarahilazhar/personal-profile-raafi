📦 Project Overview

SICERDAS (SISTEM CERDAS LAYANAN DESA) is a web-based village administration service system that enables citizens to submit document/letter requests online, track application status, and helps village staff (RT/RW/Head of Village/Operator/Admin) process approvals in a structured workflow. The platform also provides demographic dashboards and public content management (news and announcements).

🛠️ Key Features

  • Multi-role authentication (Citizen, RT, RW, Head of Village, Operator, Admin)
  • Online letter/document requests with dynamic forms & required attachments upload
  • Status tracking for submitted applications
  • Multi-level approvals workflow (RT → RW → Head of Village), with operator/admin fast approval
  • Automatic document generation (Word template .docx → PDF)
  • QR-based document verification token and embedded signature image (TTE) on generated documents
  • WhatsApp notification when the document is completed (queue/job-based)
  • Staff dashboard: application history and demographic analytics (gender, age range, education, religion, top occupations)
  • Public content management: news & announcements

💻 Technology

  • Laravel 12 (PHP 8.2)
  • MySQL Database (Eloquent ORM, Migrations, Seeders)
  • Tailwind CSS (Responsive UI)
  • Spatie Laravel Permission (Role-based access control)
  • PHPWord + DOMPDF (Generate PDF from .docx templates)
  • Simple QrCode (Document verification QR)
  • WhatsApp API integration (Fonnte / WhatsApp service layer)
