📦 Project Overview

Simantap (Sistem Manajamen Tugas Akhir dan Praktik) is a web application for academic proposal submission and verification, supporting three roles: students, lecturers (advisor & examiner), and administrators. The system manages proposal data, submission status, securely uploads documents (PDF/DOC/DOCX) with encryption, and provides approve/reject workflows with verification notes and attachment uploads. It also includes an AI-assisted evaluation feature that helps lecturers assess document similarity and novelty.

🛠️ Key Features

  • Role-based multi-user login (admin, lecturer, student)
  • Proposal submission with title, specialization, description, and document upload
  • Advisor setup (Advisor 1 & 2) per proposal
  • Secure document download and preview using server-side decryption
  • Verification workflow: approve/reject with notes and verification attachments
  • AI evaluation for Similarity & Novelty using an LLM, processed in background jobs with polling for results

💻 Technology

  • Laravel (Blade/PHP)
  • MySQL Database
  • Bootstrap for UI components
  • Laravel Queue/Jobs for asynchronous AI processing
  • LLM-based AI pipeline for Similarity & Novelty analysis
